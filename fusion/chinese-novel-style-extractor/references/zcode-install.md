# ZCode installation

Install the folder as a normal Agent Skill so that `SKILL.md` remains the entrypoint.

For a project-local installation, place the complete `chinese-novel-style-extractor` directory under `.zcode/skills/` in the target project. For a user-level installation, place it under `~/.zcode/skills/`.

Keep `scripts/`, `references/`, and `agents/` beside `SKILL.md`. Do not copy only `SKILL.md`; the workflow depends on the bundled deterministic scripts.
